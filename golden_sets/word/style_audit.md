# Word Golden Set 样式审计

日期：2026-10-25。来源为本地用户指定的私有DOCX。清单不记录源路径、文件名或哈希；只发布通用样式属性，不复制原文、表格内容、数据或图片。

## 真实版式

- 1个分节；页面约8.268×11.693英寸（A4纵向）；页边距上/下1.0/1.0、左/右1.25/1.25英寸。
- 正文样式以Normal为主；样式使用、直接格式、东亚字体、字色、字号、段落间距、标题层级及表格边框/单元格边距统计见JSON。
- DOCX主题和段落样式存在直接格式覆盖；提取时保留“继承”状态，不能把局部格式误判为文档默认值。具体文字字符频次用于识别实际表现，样式XML单独记录规则定义。
- 模板不包含来源文档中的表格内容。

## 使用边界

该Golden Set用于版式继承，字体缺失时须报告回退情况。模板是空白生产骨架，不是原报告副本。改用其他Word来源前应重新运行提取脚本并复核冲突样式。
