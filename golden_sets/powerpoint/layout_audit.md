# PowerPoint Golden Set 布局审计

来源为本地用户指定的私有PPTX；清单不记录源路径、文件名、哈希或页面内容。画布10.0×5.625英寸，仅输出通用排版和字体/颜色设置。

- 页眉与结论标题位于上方；主体从页面约六分之一高度开始；页码与授权信息位于底部。
- 图片主要用于品牌和产品识别，Logo在不同页面的位置与尺寸不完全统一，因此新模板使用可替换Logo占位框。
- 文字、数据图表和表格尽量保持原生可编辑。不同页面类型的密度差异较大，模板提供封面、结论、数据图表和对比表的基础骨架，不要求所有页面使用同一网格。
- 实际字体和颜色设置保存在`theme_manifest.json`，不包含来源页码、对象数量、Logo或图片位置。

该文件作为风格参考。研究结论、数字和原企业资产没有被带入通用模板。
